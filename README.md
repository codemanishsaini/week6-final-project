# 🎓 Student Management System

Ye mera Internship Final Project hai. Is project mein maine HTML, CSS aur JavaScript ka use karke ek website banayi hai.

## 📌 Project Ke Features
- **Add Student:** Form bhar kar naye student add kar sakte hain.
- **Delete:** Agar kisi student ka data galat hai, toh use delete kar sakte hain.
- **Responsive:** Ye website mobile, tablet aur laptop sab par sahi chalti hai.

## 🛠️ Technologies Used
- **HTML:** Website ka dhancha (structure) banane ke liye.
- **CSS:** Website ko sundar aur responsive banane ke liye (Flexbox, Grid, Media Queries).
- **JavaScript:** Add aur Delete jaise features chalane ke liye (DOM Manipulation, Arrays, Events).
- **Git & GitHub:** Code ko save aur internet par upload karne ke liye.

## 📁 Folder Structure
- `index.html` - Main webpage
- `index.css` - Styling aur design
- `script.js` - JavaScript ka logic
- `README.md` - Project ki jankari (ye file)
